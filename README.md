## Quick answers

### Can I show a PDF on a projector from my laptop?

Open vuthis.com on the display browser or the computer already driving the projector. Open vuthis.com/r on the controlling laptop, enter the screen code and choose Document. No HDMI connection is needed from the controller.

### Do the controller and screen need the same Wi-Fi?

Both need internet access; they can use different networks. Connect with the display code or QR code.

### How do I put PowerPoint on TV?

Export the slides to PDF, choose the PDF in Document and select Show now. Use Previous/Next and Fit page to present the exported pages.
